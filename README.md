# E-Commerce Transaction Management and Anomaly Detection System

Project workspace for the e-commerce transaction management and anomaly detection system.

## Repository layout

- `data/raw/` — source Olist CSV datasets
- `data/dataset_card.md` — dataset provenance, contents, and limitations
- `docs/business_process/` — process diagram and explanation
- `docs/design/` — normalization, data dictionary, and ERD
- `docs/proposal/` — project proposal
- `docs/presentation/` — phase 0 presentation
- `docs/research/` — research log
- `scripts/` — data validation utilities and their output
- `innovation/` — innovation concept and supporting notes
